새 위키 문서

문서의 제목을 정하고 카카오톡 대화 파일을 선택해주세요.

대화 내용을 담은 텍스트 파일을 첨부해주세요.

지원 형식: .txt · 파일 선택 후 파일명이 표시됩니다.

현재는 화면 미리보기 단계입니다. 선택한 파일은 전송되거나 저장되지 않으며, 위키 자동 생성 기능은 준비 중입니다.

예시 위키 보기

대화 파일은 어떻게 준비하나요?

  1. 카카오톡에서 정리하고 싶은 단톡방을 열어주세요.
  2. 채팅방 설정에서 대화 내용 내보내기를 선택해주세요.
  3. 저장한 텍스트(.txt) 파일을 위에서 선택해주세요.

대화에 포함된 개인정보를 확인하고, 참여자들의 동의를 받아 사용해주세요.
