# 대화위키

카카오톡 단톡방의 대화를 위키로 정리하는 서비스의 정적 화면 예시입니다.
별도의 JavaScript 없이 HTML 세 페이지와 공통 CSS로 구성했습니다.

## 페이지

- `index.html`: 서비스 소개와 페이지 이동
- `form.html`: 문서 제목 입력과 카카오톡 `.txt` 파일 선택
- `wiki.html`: 목차, 여행 정보, 일정표가 있는 위키 예시
- `styles.css`: 세 페이지의 공통 스타일과 모바일 화면 대응

`index.html`을 브라우저에서 직접 열거나, 프로젝트 폴더에서 아래 명령으로 실행할 수 있습니다.

```sh
npm install
npm run dev
```

배포용 정적 파일은 `npm run build` 실행 시 `dist/`에 생성됩니다.

현재 파일 전송, 대화 분석, 위키 생성·저장 및 나무위키 연동은 구현하지 않았습니다.
파일 선택은 브라우저 안에서만 이루어지며 서버로 전송되지 않습니다.
`src/`와 React 관련 의존성은 기존 프로젝트의 기본 파일로, 현재 정적 화면에서는 사용하지 않습니다.
